# -ClawBot-OpenClaw-Agent
 我构建了一个基于微信 ClawBot + 腾讯云 OpenClaw 的轻量化自动化记账 Agent，专为个人及 3-5 人小团队的日常收支管理设计。   核心痛点：   传统记账 APP 需要手动打开输入，操作繁琐，80% 的人会因忘记记录导致数据失真；   小团队共用账本时数据不同步，每次对账需要手动汇总，耗时费力；   OpenClaw 原生存在思考模式模型参数校验 bug，通 过本地反向代理中转层调用大模型。中转层同时实现思考内容自动剥离、请求参数标准化、响应格式校验三大核心功能，彻底解决了   OpenClaw 的 400 报错问题。支持多用户独立账本隔离、收支记录自动同步腾讯文档、月度收支统计自动生成，形成「微信输入→自动   解析→数据存储→文档同步」的完整闭环。
